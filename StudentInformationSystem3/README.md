# Lab 5

## Purpose
The focus on this lab is using AJAX or Asynchronous Javascript and and XML.

We firstly create HTML files for:
- Get: creates empty table, ajax gets the list of students, and displays its data received from the server.
- Post: creates a form, ajax submits, handle response confirms.
- Put: creates a form, on submission will make an ajax put request to update the student, and confirmation message.
- Delete: creates a form, makes an ajax delete, and handles with a confirmation message. 

CSS Step, just styling.



## Testing

Going to each UI for testing:

View all students:

```
http://localhost:8080/StudentInformationSystem3/Get.html
```
Add a new student:

```
http://localhost:8080/StudentInformationSystem3/Post.html
```

Update a a student:

```
http://localhost:8080/StudentInformationSystem3/Put.html
```

Delete a student from list:

```
http://localhost:8080/StudentInformationSystem3/Delete.html
```
